# HexRank 2.1.5

海克斯大乱斗胜率助手

## 功能

- 英雄胜率、选取率、场次、排名
- 海克斯 S/A/B/C/D 评级推荐
- 出装与技能加点
- 分段数据（娱乐/中分/前5%）

## 下载

- [安装版](https://github.com/ReQiLM/HexRank-2.1.5/releases/download/2.1.5/HexRank-Setup-2.1.5.exe)
- [便携版](https://github.com/ReQiLM/HexRank-2.1.5/releases/download/2.1.5/HexRank-Portable-2.1.5.zip)

## 使用

1. 游戏设为无边框或窗口化
2. 运行 HexRank
3. 自动识别英雄和海克斯

## 数据

数据来自公开数据仓库，每周更新，无需 API。
